# Valtheron AI Market Intelligence

A mobile-friendly financial market research dashboard.

## Planned features

- Forex market monitoring
- Gold and commodities analysis
- Stock market monitoring
- Cryptocurrency monitoring
- Technical analysis
- AI-assisted market research
- Economic news and event monitoring

## Data integrity

Market prices must include their source and timestamp.
Delayed data must not be represented as real-time data.
This application does not guarantee profitable trading signals.

## Technology

- Python
- FastAPI
- HTML, CSS and JavaScript
- External market-data APIs
